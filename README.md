💡 Sobre o Projeto

O Voz do Povo é uma aplicação web (PWA) desenvolvida para democratizar o acesso à informação legislativa e municipal.

Utilizamos a API do Google AI Studio (Gemini) para ler textos legislativos complexos e traduzi-los em tempo real para uma linguagem acessível e adaptada ao contexto do usuário (ex: "me explique como se fosse uma conversa de bar").

Além da tradução de leis, a plataforma empodera o cidadão com ferramentas de fiscalização de obras públicas e votação em plebiscitos locais.

📱 Funcionalidades
1. 🤖 Tradutor de Leis com IA (Google Gemini)

Simplificação Inteligente: A IA processa o texto da lei e gera um resumo claro.

Contexto Personalizado: O usuário digita um tema de interesse (ex: "Futebol", "Novela", "Gírias") e a explicação é gerada usando analogias desse universo.

Player de Áudio: Acessibilidade nativa. Ouça a explicação gerada.

Download: Acesso ao PDF original e ao resumo.

2. 🚧 Fiscal de Obras

Transparência: Monitoramento visual do status de construções públicas.

Dados Claros: Barra de progresso, orçamento gasto e previsão de entrega.

Status: Identificação visual de obras "Atrasadas" ou "Em Andamento".

3. 🗳️ Plebiscitos Digitais

Democracia Direta: Enquetes rápidas sobre decisões locais (ex: mudança de nome de rua).

Feedback: Visualização parcial dos votos da comunidade.

🛠️ Tecnologias Utilizadas

Front-end: HTML5, CSS3 (Moderno/Responsivo), JavaScript (ES6+).

Inteligência Artificial: Google AI Studio (Gemini API).

Deploy & Hospedagem: Vercel.

Ícones & Fontes: FontAwesome e Google Fonts (Inter).

🚀 Como Rodar Localmente

Caso queira clonar e testar em sua máquina:

Clone o repositório:

```
git clone https://github.com/seu-usuario/voz-do-povo.git
```
Acesse a pasta:
```
cd voz-do-povo
```

Configuração da API:

Crie um arquivo config.js (ou insira sua chave diretamente no script, caso seja apenas para teste local) com sua API Key do Google AI Studio.

Rodar:

Abra o arquivo index.html no seu navegador ou use o Live Server do VS Code.
